# CSS Variables Contract

**This is the locked vocabulary every Starting Point and base must use.** It is served at runtime by `GET /api/design-tokens.css` so a single branding change cascades to every app on the next page load — no rebuild required.

Every variable below is published on `:root`. Every consumer **must** include a fallback (`var(--color-primary, #0F766E)`) so an app degrades gracefully if the endpoint is briefly unreachable.

---

## Colors

| Variable | Default | Use |
|---|---|---|
| `--color-primary` | `#0F766E` | Primary brand colour (CTAs, links, focus rings) |
| `--color-primary-hover` | `#115E59` | Hover state for primary. **Darker** than `--color-primary`: a hover on a light canvas darkens, so a white label on it keeps AA (7.58:1) |
| `--color-accent` | `#14B8A6` | Secondary brand colour (highlights, badges) |
| `--color-on-primary` | `#FFFFFF` | Label/icon colour **on** a primary-filled surface. Use this for button text, never `--color-bg` (which breaks under a dark-background brand) |
| `--color-bg` | `#FFFFFF` | Page background |
| `--color-surface` | `#F8FAFC` | Card / panel surface |
| `--color-surface-muted` | `#F1F5F9` | Subtler surface (inputs, alt rows) |
| `--color-border` | `#E2E8F0` | Borders, dividers |
| `--color-text` | `#0F172A` | Primary text |
| `--color-text-muted` | `#475569` | Secondary text |
| `--color-text-subtle` | `#64748B` | Tertiary text, captions |
| `--color-success` | `#16A34A` | Positive feedback |
| `--color-warning` | `#D97706` | Caution |
| `--color-danger` | `#DC2626` | Errors, destructive actions |
| `--color-info` | `#2563EB` | Informational notices |

## Typography

| Variable | Default | Use |
|---|---|---|
| `--font-sans` | `system-ui, -apple-system, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif` | Default UI font |
| `--font-display` | same stack as `--font-sans` | Display/hero headings; brands may resolve it to a dedicated display face |
| `--font-mono` | `ui-monospace, SFMono-Regular, Menlo, Monaco, monospace` | Code, tabular data |
| `--text-xs` | `0.75rem` | 12px |
| `--text-sm` | `0.875rem` | 14px |
| `--text-base` | `0.9375rem` | 15px (body) |
| `--text-lg` | `1.125rem` | 18px |
| `--text-xl` | `1.25rem` | 20px |
| `--text-2xl` | `1.5rem` | 24px |
| `--text-3xl` | `1.875rem` | 30px |
| `--text-4xl` | `2.25rem` | 36px (page hero, deck h2) |
| `--text-5xl` | `3rem` | 48px (landing hero, deck h1) |
| `--text-6xl` | `3.75rem` | 60px (display/statement type) |

Display sizes (`--text-4xl` and up) want tighter leading (1.05–1.2) and slightly negative
tracking (−0.01em to −0.025em); set those per rule — they are intentionally not variables.

## Shadows

| Variable | Default |
|---|---|
| `--shadow-sm` | `0 1px 2px rgba(15, 23, 42, 0.05)` |
| `--shadow-md` | `0 4px 6px -1px rgba(15, 23, 42, 0.08), 0 2px 4px -2px rgba(15, 23, 42, 0.04)` |
| `--shadow-lg` | `0 10px 15px -3px rgba(15, 23, 42, 0.08), 0 4px 6px -4px rgba(15, 23, 42, 0.05)` |
| `--shadow-xl` | `0 24px 48px -12px rgba(15, 23, 42, 0.18)` |

Shadows always carry an offset and a soft blur — a zero-offset colored halo is decoration,
not depth.

## Brand assets

| Variable | Default |
|---|---|
| `--logo-url` | empty string when no logo is set; otherwise `url("/brand-assets/<file>")` |
| `--logo-icon-url` | empty string when no icon is set; otherwise `url("/brand-assets/<file>")` |

Consumers must check for emptiness before applying the URL (e.g. `.logo[style*="--logo-url"] { background-image: var(--logo-url); }`).

## How to use

```css
/* Good: every var has a fallback */
.btn-primary {
  background: var(--color-primary, #0F766E);
  color: var(--color-bg, #FFFFFF);
  padding: var(--space-3, 0.75rem) var(--space-4, 1rem);
  border-radius: var(--radius-md, 0.5rem);
  font-family: var(--font-sans, system-ui, sans-serif);
  font-size: var(--text-base, 0.9375rem);
  box-shadow: var(--shadow-sm, 0 1px 2px rgba(15, 23, 42, 0.05));
}

/* Bad: no fallback */
.btn-primary { background: var(--color-primary); }

/* Bad: hex literal — breaks brand inheritance */
.btn-primary { background: #0F766E; }
```

## Where this is served

- Endpoint: `GET /api/design-tokens.css` (same-origin to every app)
- Generated by: `api/src/services/design-tokens.ts`
- Sources: the platform default variable bag (`DEFAULT_VARS` in that file) overlaid with the requesting app's ORG branding (brand research), resolved server-side from `?app=` or the `/apps/<slug>/` Referer. A base's `tokens.json` is reference-only and deliberately NOT consumed (`api/src/apps/base-loader.ts`).
- Cache: ETag `W/"<org updatedAt|default>:<hash>"`; `Cache-Control: public, max-age=60, must-revalidate`
- Linked from: `api/assets/scaffold-templates/index.html` (every app)

## Migration note

Apps built before this contract existed continue to read `frontend/src/tokens.json` at build time and apply inline styles. They keep working but **do not auto-rebrand**. Rebuild to inherit the new pattern.
